TREX — PREMIUM HOME FITNESS PLATFORM

You are the Lead Product Designer, Senior Full-Stack Engineer, UI/UX Designer, Motion Designer, and Technical Architect responsible for building a production-quality fitness platform called TREX.

TREX is a visual home-gym platform that allows users to train from home using guided workout programs designed around specific goals such as:

* Lose body fat
* Gain muscle
* Build chest
* Build arms
* Build shoulders
* Grow legs
* Build abs/core
* Improve strength
* Improve endurance
* Full-body transformation
* Beginner fitness
* Advanced fitness

The website must feel like a premium fitness product, not a normal template website.

DO NOT build a basic website.

DO NOT create a generic Bootstrap-style dashboard.

DO NOT make it look like a school project.

DO NOT use excessive cards everywhere.

The experience should feel closer to a premium combination of a fitness streaming platform + personal trainer + modern fitness app.

30. REAL PRODUCT BEHAVIOR

If streak changes:

If subscription changes:

reflect it throughout the application.

If onboarding changes:

update the user’s profile.

If a workout is bookmarked:

persist it.

If a user logs out:

protected pages become inaccessible.

Build actual functionality.
